# 学习彩蛋与游戏验收

## 使用与部署

后台“彩蛋设置 → 学习彩蛋”管理全局规则，默认关闭，默认奖励时长为 15 分钟。已保存的管理员配置仍按保存值生效。迁移 `0014_easter_eggs` 新增设置、每日奖励、游玩会话三张表；现有学生与成绩无需迁移或补发。三个 Dockerfile 都包含游戏资源与共享主题，无额外游戏服务。

游戏源位于 `backend/game_assets`，运行文件与原目录独立。共享的 `tokens.css` 同时用于前端页面与 iframe。`bridge.js` 在游戏脚本之前加载，限制未授权启动，统一消息、心跳失联暂停、静音与销毁。游戏玩法和渲染仍由各自引擎负责。

`POST /api/easter-eggs/rewards/{id}/prepare` 是不计时的准备接口，返回与学生、奖励、游戏及实例绑定的临时资源地址。开始接口重复请求保持截止时间；接管需显式传 `take_over: true`，旧实例心跳失效。心跳每 5 秒核验；超过 15 秒无法确认连接时停止交互，奖励时间仍流逝。管理员关闭在下次核验时生效，断网页面也受 15 秒本地租约限制。前端和游戏适配层分别检查期限。

奖励展示版本用于区分初次解锁与开始前升级。庆祝展示记录按学生、奖励及版本保存在浏览器；可用时通过 Web Locks 协调标签页。动画不会发奖或开始扣时。游戏存档使用学生和游戏命名空间，清理浏览器数据会清除本机游戏进度，但不会增加奖励时间或重置服务端资格。

## 自动化检查

```powershell
cd backend
..\.venv\Scripts\python.exe -m pytest -q
cd ../frontend
npm test -- --maxWorkers=2
npm run build
```

浏览器脚本使用独立临时数据库和本地测试账号，不读取生产数据。先构建前端，然后从项目根目录启动测试服务：

```powershell
.venv\Scripts\python.exe backend/tests/reward_browser_server.py
```

另开终端安装独立浏览器测试依赖并执行：

```powershell
cd frontend/tests
npm install
npm test
```

默认使用本机 Chrome；可通过 `REWARD_BROWSER_PATH` 指定浏览器执行文件。若已有 Playwright 安装，可设置 `PLAYWRIGHT_MODULE` 为其 `@playwright/test` 模块路径，直接运行 `node frontend/tests/rewards.browser.cjs`。测试服务固定监听 `127.0.0.1:8093`，每次启动创建新的临时数据库；完整脚本每轮需重启测试服务以重置一次性奖励。

脚本覆盖解锁动画、准备不扣时、冒险键盘操作、赛车加速、切换、全屏、刷新、真实计时到期、断网暂停与恢复、标签页接管、管理员关闭、减少动态效果及手机触控设备提示，截图输出到 `output/reward-qa/`。测试奖励设为 1 分钟，因此整轮约需 2 分钟。使用已有 Playwright 时，先运行 `rewards.browser.cjs`，再运行同目录的 `rewards.resilience.cjs`。

## 人工验收

- 按分数与随机模式各完成一轮达标练习，检查礼盒揭晓、双游戏共享时长、开始前升级与随机结果固定。
- 检查首页、习题结果、游戏准备、操作指南、暂停、结算和结束页面的字体、配色、按钮与布局；全屏应保留时间、切换、指南和返回入口。
- 小屏及系统减少动态效果下，确认动画可跳过、不抢焦点；赛车在纯触控设备准备前给出说明。
- 断网超过 15 秒应暂停；恢复后核验原截止时间，手动继续游戏。跨标签页接管后原页面应停止，管理员关闭后不能继续或通过旧地址重新进入。
- 80/90 分均指准确得分率门槛；开始前未领取的奖励在北京时间午夜失效，已经开始的奖励保持原截止时间。

## 验证范围

本次实现已通过后端全量 112 项测试、前端全量 201 项测试、`npm run build` 和 Dockerfile.cn/local 使用的 TypeScript + Vite 构建命令。从 `0013_attempt_request_id` 升级至 `0014_easter_eggs` 后，`alembic check` 未发现模型与迁移差异。

两组 Chrome 浏览器验收脚本均通过，未捕获页面脚本异常，包括真实一分钟到期与断网、接管、关闭流程。当前开发环境没有 Docker/Podman，未实际构建或启动容器；三个 Dockerfile 的资源复制路径已同步更新。Vite 仍提示主应用包超过 500 kB，游戏页面和庆祝动画已分包按需加载。

客户端离线小游戏采用服务端访问校验与双层运行期限控制，用于正常浏览器流程的学习奖励管理。游戏渲染在浏览器本地执行；服务端不接收或信任客户端游戏成绩作为习题分数。
